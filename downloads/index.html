Aegis — λήψεις LAN

Εγκατάσταση από το τοπικό δίκτυο (χωρίς GitHub / cloud block).

Προτεινόμενο: Setup (.exe) από εδώ
  1. Κατέβασε Aegis_latest_x64-setup.exe
  2. Τρέξε το (per-user, χωρίς UAC).
  3. Server URL: http://192.168.1.235:3001

Το ίδιο αρχείο από GitHub συχνά παίρνει ψευδή «virus detected» — μόνο από αυτό το LAN URL.

Εναλλακτικά: portable ZIP
  1. Aegis_latest_windows_x64.zip → unzip → Aegis.exe
  2. Αν μπλοκάρει: Unblock-File .\Aegis.exe

Το ZIP μπορεί να χτυπήσει τοπικό Defender ML ακόμα και από LAN· προτίμησε το Setup παραπάνω.

Όλα τα αρχεία: λίστα φακέλου · Updates: /latest.json
